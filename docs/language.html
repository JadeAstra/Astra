Keywords

Twenty-five words are reserved and are never names: val var fun class this super return if else while for in break continue true false null try catch throw import is and or when. The others below are keywords only where they are written: value, data or init can still name a variable or a function.

Declaring things

val, var
A variable: val is given its value once, var may be given another. The type comes from the value unless it is written after a colon; a variable of type any holds anything, and needs a cast before most uses. 
val fixed = 3
var count : int = 0
count += fixed
const
A val whose value is worked out when the program is compiled, from literals and other constants, and written into each place it is used. Declared at the top level, in an object or in a class's static { } block. 
const maxRows = 1000
fun, return
A function: its parameters with their types, then its result type after a colon (none for a function that gives nothing). return leaves it, with the value it gives; a body written => expression gives that expression. 
fun square(x : int) : int { return x * x }
fun cube(x : int) : int => x * x * x
vararg
A parameter that takes any number of arguments, as a list. One per function. 
fun total(vararg parts : int) : int {
  var sum = 0
  for (p in parts) { sum += p }
  return sum
}
total(1, 2, 3)    // 6
class
A class: the fields in its header (val or var in front makes a field; a bare name is only a parameter of the initializer), then its body. After a colon, at most one superclass, with the arguments for it, and any number of interfaces. Every class can be extended and every member overridden. 
class Shape(val name : string) {
  fun describe() : string => "a shape called $name"
}
class Square(val side : int) : Shape("square")
interface
What classes promise to have: functions and properties without a body, which each class supplies, and functions with one, which they inherit. An interface has no objects of its own. 
interface Named {
  fun name() : string
  fun greeting() : string => "hello, ${name()}"
}
abstract
An abstract class is never made itself, only its subclasses are; an abstract member has no body, and each subclass writes it. 
abstract class Base : Named {
  abstract fun id() : int
  override fun name() : string => "base ${id()}"
}
data
A class compared, hashed and printed by the fields of its header, which are also the parts it comes apart into (val (name, age) = user). It has a copy that changes some of them. 
data User(val name : string, val age : int)
User("Ann", 30) == User("Ann", 30)    // true
print(User("Ann", 30))                // User(name="Ann", age=30)
value
A value type: a data class whose values have no identity of their own. A value is copied where it is given or kept, and a list of them keeps them one after another in one block of memory, with no object for each. 
value Point(var x : int, var y : int)
mutating
A function of a value type that may give its var fields new values. It is called on a place that holds the value (a var, a field, an item of a list), which keeps the result. 
value Point(var x : int, var y : int) {
  mutating fun moveBy(dx : int, dy : int) { x += dx; y += dy }
}
var p = Point(1, 2)
p.moveBy(10, 10)    // p is Point(x=11, y=12)
enum
enum Name { A, B } is a class whose only objects are the entries listed; Name.entries lists them. enum class and enum interface declare a fixed set of kinds: the classes and objects that extend it, all written in its file, so that a when over them needs no else. 
enum Direction { NORTH, EAST, SOUTH, WEST }

enum class Event {
  class Click(val x : int) : Event()
  object Close : Event()
}
fun handle(e : Event) : string => when (e) {
  is Event.Click -> "click at ${e.x}"
  Event.Close -> "close"
}
object
object Name { ... } declares a class and makes its one object, reached by the name. Where a value is expected, object : Listener { ... } is an object of a class with no name. 
object Counter {
  var hits = 0
  fun hit() { hits += 1 }
}
Counter.hit()
annotation
An annotation: declared like a class, with the values it holds in its header, and written with @ on a class, a function, a field or a parameter. Nothing is made from it but what reflection reads. 
annotation JsonField(val name : string = "")
class Row(@JsonField("row_id") val id : int, val label : string)
for (f in Row#.fields) { print(f.annotation<JsonField>()?.name ?: f.name) }    // row_id, label
type
Another name for a type, not a new type: the two are the same everywhere. 
type Table = Map<string, List<int>>
val t : Table = {"a": [1, 2]}
extend
Makes classes someone else wrote fit an interface of this program. Where the names differ, the properties written in its body bridge them. 
class Crate(val count : int)
interface Sized { val size : int }
extend Crate : Sized { val size : int get() => count }

Members, access and kinds of function

this, super
this is the object a method runs on (a field's name alone reaches it too). super.name is the member the superclass has under that name, for a method that adds to the one it overrides. 
override fun describe() : string => super.describe() + " of area $area"
init, constructor
init { ... } runs when an object is made, in order with the fields' starting values. constructor(...) : this(...) is another way of making one, which hands its work on to the class's own initializer. 
class Square(val side : int) : Shape("square") {
  var area = 0
  init { area = side * side }
  constructor(text : string) : this(text.toInt())
}
override
Written in front of a member that takes the place of one the class would otherwise inherit, from its superclass or an interface. Leaving it out there is an error, and so is writing it where nothing is replaced.
static
A class's one static { ... } block holds the members of the class itself rather than of its objects, reached as ClassName.member. 
class Temperature(val celsius : float) {
  static {
    fun fromFahrenheit(f : float) : Temperature => Temperature((f - 32.0) * 5.0 / 9.0)
  }
}
Temperature.fromFahrenheit(212.0).celsius    // 100.0
get, set, field
A property's own code, written under it: get() works out its value each time it is read, set(value) runs when it is assigned. In them, field is the value the property keeps. private set (or protected set, internal set) lets everyone read it and only that code assign it. 
class Account {
  var balance = 0
    private set
  var owner = ""
    set(value) { field = value.trim() }
  val isEmpty : bool get() => balance == 0
}
private, protected, internal, public
Who may use a declaration. private: a member only its class's code, a top-level declaration only its file. protected: that, and code written in a subclass, on objects of that subclass. internal: code of the same library (a program is one library; so is Jade). public is accepted and changes nothing: everything else is open to everyone.
lateinit
A var field given its value after the object is made. Reading it before that is an error.
lazy
A val whose value is worked out the first time it is read, and kept. 
class Config {
  lateinit var path : string
  lazy val size : int = path.size
}
atomic
A var field that any core of a parallel section may change, in one step, through +=, -=, = max(...), = min(...) and compareAndSet. 
class Tally { atomic var hits = 0 }
val tally = Tally()
(0 ..< 1000).toList().parallelStream().forEach { tally.hits += 1 }    // tally.hits is 1000
op
An operator of a class or value type: op +(other), op [](index), op ==(other) and the others, used as the operator is. 
value Money(val cents : int) {
  op +(other : Money) : Money => Money(cents + other.cents)
}
Money(150) + Money(250)    // Money(cents=400)
infix
A function of one parameter, a member or an extension, called between its two values with no dot or brackets. 
infix fun int.times(text : string) : string => text.repeat(this)
3 times "ab"    // "ababab"
inline
A function copied into each place it is called, with the lambdas given to it, so a lambda costs nothing and a return in it leaves the function around the call. 
inline fun twice(action : () -> unit) { action(); action() }
tail
Says that each call the function makes of itself is its last step. A function calling itself as its last step is made a loop with or without the word; with it, a call that is not its last step is an error. 
tail fun countDown(n : int) : int {
  if (n == 0) { return 0 }
  return countDown(n - 1)
}
suspend
A function that may wait (for a timer, a file, an answer), setting its task aside while it does. It is called only where waiting is possible: from another suspend function, at the top level of a script, or in the lambda given to task or thread. There is no await at the call. 
suspend fun later(x : int) : int {
  Thread.sleep(1.milliseconds)
  return x * 2
}
task { print(later(21)) }    // 42
throws
Written after a function's result type: the checked exceptions it may throw, which callers handle. The compiler works these out on its own inside a program; a library's public functions, and declarations with no body, say them. 
fun readConfig(path : string) : string throws IOException => Path(path).readText()
external
Only in the standard library: a function, property or object written in C++, declared in Astra so that its types and parameter names are known. It has no body. The reference below leaves the word out.

Choosing and repeating

if, else
Runs one block or the other. Written where a value is wanted, it gives the value of the block that runs; the braces are always written. 
val sign = if (count > 0) { "positive" } else { "not positive" }
when
Picks the first branch that fits: a value it equals, is Type, in a range or a collection, or, with no subject, a condition. Its value is that of the branch taken. when (val x = ...) names the subject for the branches. 
fun describe(x : any) : string {
  return when (x) {
    0 -> "zero"
    is string -> "a string"
    in 1..9 -> "a digit"
    else -> "something else"
  }
}
while, do
while (condition) { ... } repeats while the condition holds, testing it first; do { ... } while (condition) tests it after each run. 
do { n -= 1 } while (n > 3)
for, in
Goes over what a range, a list, a map, a set, a string or a sequence gives, an item at a time. a..b includes b, a..<b stops before it. 
for (i in 0 ..< 3) { write(i, " ") }    // 0 1 2
break, continue
break leaves the loop it is in; continue goes on to its next round. 
while (true) {
  n += 1
  if (n % 2 == 0) { continue }
  if (n > 5) { break }
}

Errors

throw
Stops the code with an exception, any Throwable: one of the standard library's (see errors.astra below) or a class of the program's own that extends Exception.
try, catch, finally
try runs a block; a catch (e : Kind) after it runs when the block throws an exception of that kind (catch (e) catches any Exception); finally runs last in every case, after any value to return is worked out. 
try {
  risky(-1)
} catch (e : IllegalArgumentException) {
  print("caught", e.message)
} finally {
  print("always")
}

Values, tests and types

true, false, null
The two values of a bool, and the absence of a value. Only a type written with ? (string?) holds null; x ?: other gives other when x is null, and x?.name gives null instead of failing. 
val maybe : string? = null
maybe ?: "none"    // "none"
and, or
Both, or either, of two conditions; the second is worked out only when the first does not already decide. ! is not. 
n > 0 and n < 10
is
Whether a value is of a type (!is: whether it is not). After a test that holds, the value is known to be of that type. 
if (anything is string) { print(anything.size) }
as
value as Type insists on the type, an error if it is not; as? gives null instead. In an import, as gives the module another name. 
val s = anything as string
val notInt = anything as? int    // null
in
Besides for: x in collection is whether the collection holds x (!in: whether it does not), and in a when, a branch for values in a range or a collection.
accepts
In a type argument of a list that may be changed: open List<accepts Button> takes a list of Button or of any type above it, to which a Button can be added. 
fun addButton(into : open List<accepts Button>) { into.add(Button()) }
val widgets : open List<Widget> = []
addButton(widgets)
open (in a type)
A list, map or set written plainly is one that may only be read; open List<T> is one that may be changed. In front of a declaration the word is an error (see below).
default
In an index, the value to give for a key a map does not have: counts[word, default = 0]. 
for (word in ["a", "b", "a"]) { counts[word] = counts[word, default = 0] + 1 }
it
The one parameter of a lambda that names none. 
[1, 2, 3].map { it * 10 }    // [10, 20, 30]

Files and libraries

import
Brings in another file or library: import NsText reaches its names as NsText.Block, import NsText.* by their bare names, import NsText as text under a name of the importer's choosing. A path of folders is written with dots, or in quotes (import "modules/strutil.astra"). The standard library needs no import: every program has all of it.

builtins.astra

Built-in functions and types

The functions every program has, and the methods and properties of the built-in types: strings, numbers, lists, maps, sets, ranges and bytes. Where one name takes different shapes (add(item) and add(index, item)), each is listed, and a call means the one its arguments fit.

Functions

fun print(vararg items : any?)#

Writes items to the output as text, a space between each two, and then a line end. A string is written as it is; in a list or a map it is shown in quotes.

print("total", 3, [1, 2])   // total 3 [1, 2]
fun write(vararg items : any?)#

Writes items to the output as print does, but with nothing between them and no line end.

fun type(value : any?) : string#

The name of the type of value: "int", "float", "string", "bool", "char", "byte", "null", "List", "Map", "Set", "Range", "Bytes", "Function", or the name of its class.

fun Range(first : int, end : int = 0, step : int = 1) : Range#

The ints from first up to end, not including end, going by step; with one argument, from 0 up to that number. A negative step counts down. An IllegalArgumentException for a step of 0.

Range(5).toList()          // [0, 1, 2, 3, 4]
Range(10, 0, -3).toList()  // [10, 7, 4, 1]
fun Bytes(source : any) : Bytes#

New bytes: Bytes(16) is sixteen zeros, Bytes([1, 2, 255]) the numbers of a list, and Bytes(other) a copy of other bytes. An IllegalArgumentException for a negative size, a number outside 0 to 255, or anything else; text becomes bytes with toBytes().

fun args() : open List<string>#

The arguments the program was started with, those after the script's name, as a new list.

fun assert(condition : bool, message : string = "assertion failed")#

Nothing when condition is true; otherwise an AssertionError with message.

fun hash(vararg values : any?) : int#

The hash of several values together, wrapping at 32 bits inside, as Java's Objects.hash.

fun clock() : float#

A time in seconds, as a float, from a clock that only goes forward: the difference between two readings is the time that passed. What it counts from is not fixed.

fun compareValues(a : any?, b : any?) : int#

How a and b are ordered: negative, zero or positive, as a comparator gives. Numbers by size, strings by their characters, chars by their numbers, false before true, and null before everything else. A ClassCastException for two values that cannot be compared.

fun exit(code : int = 0) : nothing#

Ends the program at once, with code as its exit status; finally blocks do not run.

fun flush()#

Sends on at once whatever print and write have written. Output to a file or to another program is otherwise sent in pieces, and at the latest when the program ends.

fun input(prompt : string = "") : string?#

Writes prompt, then reads one line of input and gives it without its line end; null when the input has ended. Other threads go on while it waits.

fun <T> maxOf(first : T, vararg rest : T) : T#

The largest of the values given, compared as compareValues does; the first of them where several are as large.

maxOf(3, 7, 2)   // 7
fun <T> minOf(first : T, vararg rest : T) : T#

The smallest of the values given, compared as compareValues does; the first of them where several are as small.

string

val string.size : int#

The number of characters.

val string.lastIndex : int#

The position of the last character, size - 1: -1 for "".

val string.indices : Range#

The positions of the characters, 0..<size.

val string.code : int#

The number of the first character, its Unicode code point: "A".code is 65. An UnsupportedOperationException for "".

fun string.upper() : string#

The text with every letter in upper case, not only the ASCII ones.

fun string.lower() : string#

The text with every letter in lower case, not only the ASCII ones.

fun string.trim() : string#

The text without the spaces, tabs and line ends at its start and at its end.

fun string.trimStart() : string#

The text without the spaces, tabs and line ends at its start.

fun string.trimEnd() : string#

The text without the spaces, tabs and line ends at its end.

fun string.trimIndent() : string#

For text written over several lines in the source: the indentation shared by all the lines with something on them taken away, and a first and a last line that are blank dropped.

fun string.trimMargin(marginPrefix : string = "|") : string#

For text written over several lines in the source: on each line, the spaces and tabs up to marginPrefix and the prefix itself taken away, and a first and a last line that are blank dropped. A line without the prefix is kept as it is.

fun string.split() : open List<string>#

The words of the text: the parts between runs of whitespace, none of them empty, as a new list.

" a  b ".split()      // ["a", "b"]
fun string.split(delimiter : string) : open List<string>#

The parts of the text between the places where delimiter is, as a new list; an empty delimiter gives each character.

"a,b,,c".split(",")   // ["a", "b", "", "c"]
fun string.split(delimiter : char) : open List<string>#

The parts of the text between the places where the character delimiter is, as a new list.

fun string.lines() : open List<string>#

The lines of the text without their line ends ("\n" or "\r\n"), as a new list. Text that ends in a line end gives an empty last line.

fun string.repeat(times : int) : string#

The text times times over; "" for 0. An IllegalArgumentException for a negative times.

fun string.reversed() : string#

The characters in the opposite order.

fun string.contains(other : string, ignoreCase : bool = false) : bool#

True when other is somewhere in the text; always true for "".

fun string.contains(other : char, ignoreCase : bool = false) : bool#

True when the character other is in the text.

fun string.startsWith(prefix : string, ignoreCase : bool = false) : bool#

True when the text begins with prefix.

fun string.startsWith(prefix : char, ignoreCase : bool = false) : bool#

True when the text begins with the character prefix.

fun string.endsWith(suffix : string, ignoreCase : bool = false) : bool#

True when the text ends with suffix.

fun string.endsWith(suffix : char, ignoreCase : bool = false) : bool#

True when the text ends with the character suffix.

fun string.indexOf(other : string, startIndex : int = 0, ignoreCase : bool = false) : int#

The position where other first appears at or after startIndex, or -1 where it does not. A negative startIndex is taken as 0.

fun string.indexOf(other : char, startIndex : int = 0, ignoreCase : bool = false) : int#

The position where the character other first appears at or after startIndex, or -1.

fun string.lastIndexOf(other : string, startIndex : int? = null, ignoreCase : bool = false) : int#

The position where other last appears, beginning at or before startIndex, or -1 where it does not. Without startIndex (or with null) the whole text is searched, from its end; a negative one gives -1.

fun string.lastIndexOf(other : char, startIndex : int? = null, ignoreCase : bool = false) : int#

The position where the character other last appears, at or before startIndex where one is given, or -1.

fun string.replace(oldValue : string, newValue : string, ignoreCase : bool = false) : string#

The text with every oldValue in it replaced by newValue; the text as it is when oldValue is "".

fun string.replace(oldChar : char, newChar : char, ignoreCase : bool = false) : string#

The text with every oldChar in it replaced by newChar.

fun string.equals(other : any?, ignoreCase : bool = false) : bool#

True when other is a string with the same characters; false for anything that is not a string.

fun string.compareTo(other : string, ignoreCase : bool = false) : int#

How the text is ordered against other, character by character by their numbers: negative, zero or positive. "B" comes before "a" unless ignoreCase.

fun string.isEmpty() : bool#

True when the text has no characters.

fun string.isNotEmpty() : bool#

True when the text has at least one character.

fun string.isBlank() : bool#

True when the text is empty or only spaces, tabs and line ends.

fun string.isNotBlank() : bool#

True when the text has something besides spaces, tabs and line ends.

fun string.isLetter() : bool#

True when every character is a letter; false for "".

fun string.isDigit() : bool#

True when every character is a digit; false for "".

fun string.isLetterOrDigit() : bool#

True when every character is a letter or a digit; false for "".

fun string.isWhitespace() : bool#

True when every character is whitespace: a space, a tab, a line end; false for "".

fun string.isUpperCase() : bool#

True when every character is an upper-case letter; false for "", and for "A1".

fun string.isLowerCase() : bool#

True when every character is a lower-case letter; false for "".

fun string.padStart(size : int, padChar : char = ' ') : string#

The text made size characters long with padChar put before it; the text as it is when it is that long already.

"7".padStart(3, '0')   // "007"
fun string.padEnd(size : int, padChar : char = ' ') : string#

The text made size characters long with padChar put after it; the text as it is when it is that long already.

fonts.astra

Fonts, text and pictures

The text engine: reading font files, measuring text and drawing it into a picture, all by code of Astra's own. The system is asked for one thing only, which font files are installed. The same font file gives the same numbers and the same pixels everywhere.

val font = Font("Segoe UI", 14, bold = true)
val page = Image(font.width("Hello") + 20, font.lineHeight + 20, Color.white)
val canvas = page.canvas()
canvas.font = font
canvas.drawString("Hello", 10, 10 + font.ascent)
page.save("hello.png")

Measuring and drawing go by one rule. A character's width is its width in the font, scaled to the size and rounded to a whole pixel; a text's width is the sum of its characters' widths; and each character is drawn where the widths before it add up to. So width("abc") is exactly where "abc" ends when drawn, and a caret placed by measuring sits on the text.

On a dense screen a font is made with a scale (1.5, 2): its numbers are then in the screen's own pixels, which is where the rounding has to happen, and a size in the units the layout works in is the number divided by the scale.

What it does not do yet: scripts whose letters join or reorder (Arabic, Devanagari), right-to-left text, and marks placed on other letters. One character is one glyph.

io.astra

Readers, writers, processes and sockets

Reading and writing a piece at a time, programs started from this one, and connections over the network.

Anything here that waits (a read, an accept, waitFor) is written as an ordinary call:

- on a thread it blocks that thread, and the other threads go on;
- in a task on the main thread the task is set aside meanwhile, and the event loop goes
  on, so a window stays live;
- on the main thread outside a task it blocks the main thread.

What text is read and written in. Astra's own text is UTF-8, the default everywhere; the others are for files, programs and protocols that use them (mail's Latin-1, Windows' UTF-16). A character the set has no place for is written as '?', and bytes that spell no character are read as U+FFFD.

parallel.astra

Parallel sections

The items of a list worked on by several cores at once, on the objects themselves:

balls.parallelStream().forEach { it.move(width, height, steps) }
val totals = orders.parallelStream().map { priceOf(it) }.toList()

Threads take turns, and workers work on copies. Here the cores really run at the same time on the same objects, which is safe because of one rule that the runtime holds each core to:

- a core may change the item it was given, and anything it makes itself;
- everything else it may read and not change: the variables around the lambda, other
  lists and objects, and whatever an item holds that is an object of its own.

A lambda that keeps to that runs on every core. One that does not, { it.move(); moved.add(it) } say, gets an error the first time it runs: it never damages anything. Results come back by being returned: map, filter, sumOf and the rest put them together afterwards.

Nothing waits inside a section: no lock, no reading or writing, no setting a task aside. The section itself is an ordinary call, which returns when every core has finished. A section may start sections of its own, and parallel({ a }, { b }) runs functions at once; the cores share the work out between them as they come free. What every core may change is an Atomic, an atomic var field, a SharedMap or a SharedSet; gather gives each core a result of its own, merged at the end.

Sequences

A sequence gives its items one at a time, as they are asked for: nothing is worked out ahead, and nothing is kept, so a sequence can be endless, or longer than would fit in memory.

val squares = generateSequence(1) { it + 1 }.map { it * it }
print(squares.filter { it % 3 == 0 }.take(5).toList())     // [9, 36, 81, 144, 225]

val fibonacci = sequence {
  var (a, b) = 0 to 1
  while (true) {
    yield(a)
    (a, b) = b to a + b
  }
}

map, filter, take and the others make a new sequence, which does its work as its items are asked for; toList, first, count, fold and the others ask for them. Each time a sequence is gone over, it starts again from the beginning.

Tasks

A task is a function that can set itself aside in the middle of a call and be taken up again later, where it was, without holding a thread meanwhile (Kotlin's coroutine). Code that asks one thing and then another reads top to bottom:

suspend fun ask(question : string) : string => suspendTask { resume -> dialog.prompt(question) { answer -> resume(answer) } }

task {
  val name = ask("Name?")
  val colour = ask("Favourite colour, $name?")
  save(name, colour)
}

task { } gives a Job of what the block returns (Kotlin's async): then { } runs with it on the event loop, get() waits for it. A function that may wait says so with suspend, and the checker holds callers to it. Waiting in a task on the main thread sets the task aside and lets the event loop go on; anywhere else it blocks the thread.

Threads

Threads share everything: a variable or an object is the same one on every thread. One thread runs Astra code at a time, and they change places at calls and at the ends of loop bodies, so anything longer than that which must not be interrupted holds a Lock's key. They are for blocking work and ported code; workers and parallel sections use the cores.

val loading = thread(name = "loader") { load(file) }    // a Job of what the block gives

A program ends when its script has finished, every thread that is not a daemon has too, and the event loop has nothing left.

Workers

class Worker#

A worker is a second copy of the runtime, on a thread of its own, running a script of its own. Unlike a thread it runs at the same time as the program that started it, on another core: that is what it is for. The price is that the two share nothing, not a variable and not an object. They exchange messages, and a message is copied.

In the program:

val worker = Worker("primes.astra")         // the script, next to this file
worker.onMessage = { result -> print("the worker found", result) }
worker.post({"upTo": 100000})

In primes.astra, where Worker.parent is the program that started it:

Worker.parent.onMessage = { job -> Worker.parent.post(countPrimes(job["upTo"])) }

A message can hold numbers, strings, booleans, null, bytes, and lists and maps of those. Frozen data in one is shared rather than copied, and bytes can be handed over. Messages arrive on the event loop of the side they are sent to, one at a time.

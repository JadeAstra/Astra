Keywords

Twenty-five words are reserved and are never names: val var fun class this super return if else while for in break continue true false null try catch throw import is and or when. The others below are keywords only where they are written: value, data or init can still name a variable or a function.

Declaring things

val, var
A variable: val is given its value once, var may be given another. The type comes from the value unless it is written after a colon; a variable of type any holds anything, and needs a cast before most uses. 
val fixed = 3
var count : int = 0
count += fixed
const
A val whose value is worked out when the program is compiled, from literals and other constants, and written into each place it is used. Declared at the top level, in an object or in a class's static { } block. 
const maxRows = 1000
fun, return
A function: its parameters with their types, then its result type after a colon (none for a function that gives nothing). return leaves it, with the value it gives; a body written => expression gives that expression. 
fun square(x : int) : int { return x * x }
fun cube(x : int) : int => x * x * x
vararg
A parameter that takes any number of arguments, as a list. One per function. 
fun total(vararg parts : int) : int {
  var sum = 0
  for (p in parts) { sum += p }
  return sum
}
total(1, 2, 3)    // 6
class
A class: the fields in its header (val or var in front makes a field; a bare name is only a parameter of the initializer), then its body. After a colon, at most one superclass, with the arguments for it, and any number of interfaces. Every class can be extended and every member overridden. 
class Shape(val name : string) {
  fun describe() : string => "a shape called $name"
}
class Square(val side : int) : Shape("square")
interface
What classes promise to have: functions and properties without a body, which each class supplies, and functions with one, which they inherit. An interface has no objects of its own. 
interface Named {
  fun name() : string
  fun greeting() : string => "hello, ${name()}"
}
abstract
An abstract class is never made itself, only its subclasses are; an abstract member has no body, and each subclass writes it. 
abstract class Base : Named {
  abstract fun id() : int
  override fun name() : string => "base ${id()}"
}
data
A class compared, hashed and printed by the fields of its header, which are also the parts it comes apart into (val (name, age) = user). It has a copy that changes some of them. 
data User(val name : string, val age : int)
User("Ann", 30) == User("Ann", 30)    // true
print(User("Ann", 30))                // User(name="Ann", age=30)
value
A value type: a data class whose values have no identity of their own. A value is copied where it is given or kept, and a list of them keeps them one after another in one block of memory, with no object for each. 
value Point(var x : int, var y : int)
mutating
A function of a value type that may give its var fields new values. It is called on a place that holds the value (a var, a field, an item of a list), which keeps the result. 
value Point(var x : int, var y : int) {
  mutating fun moveBy(dx : int, dy : int) { x += dx; y += dy }
}
var p = Point(1, 2)
p.moveBy(10, 10)    // p is Point(x=11, y=12)
enum
enum Name { A, B } is a class whose only objects are the entries listed; Name.entries lists them. enum class and enum interface declare a fixed set of kinds: the classes and objects that extend it, all written in its file, so that a when over them needs no else. 
enum Direction { NORTH, EAST, SOUTH, WEST }

enum class Event {
  class Click(val x : int) : Event()
  object Close : Event()
}
fun handle(e : Event) : string => when (e) {
  is Event.Click -> "click at ${e.x}"
  Event.Close -> "close"
}
object
object Name { ... } declares a class and makes its one object, reached by the name. Where a value is expected, object : Listener { ... } is an object of a class with no name. 
object Counter {
  var hits = 0
  fun hit() { hits += 1 }
}
Counter.hit()
annotation
An annotation: declared like a class, with the values it holds in its header, and written with @ on a class, a function, a field or a parameter. Nothing is made from it but what reflection reads. 
annotation JsonField(val name : string = "")
class Row(@JsonField("row_id") val id : int, val label : string)
for (f in Row#.fields) { print(f.annotation<JsonField>()?.name ?: f.name) }    // row_id, label
type
Another name for a type, not a new type: the two are the same everywhere. 
type Table = Map<string, List<int>>
val t : Table = {"a": [1, 2]}
extend
Makes classes someone else wrote fit an interface of this program. Where the names differ, the properties written in its body bridge them. 
class Crate(val count : int)
interface Sized { val size : int }
extend Crate : Sized { val size : int get() => count }

Members, access and kinds of function

this, super
this is the object a method runs on (a field's name alone reaches it too). super.name is the member the superclass has under that name, for a method that adds to the one it overrides. 
override fun describe() : string => super.describe() + " of area $area"
init, constructor
init { ... } runs when an object is made, in order with the fields' starting values. constructor(...) : this(...) is another way of making one, which hands its work on to the class's own initializer. 
class Square(val side : int) : Shape("square") {
  var area = 0
  init { area = side * side }
  constructor(text : string) : this(text.toInt())
}
override
Written in front of a member that takes the place of one the class would otherwise inherit, from its superclass or an interface. Leaving it out there is an error, and so is writing it where nothing is replaced.
static
A class's one static { ... } block holds the members of the class itself rather than of its objects, reached as ClassName.member. 
class Temperature(val celsius : float) {
  static {
    fun fromFahrenheit(f : float) : Temperature => Temperature((f - 32.0) * 5.0 / 9.0)
  }
}
Temperature.fromFahrenheit(212.0).celsius    // 100.0
get, set, field
A property's own code, written under it: get() works out its value each time it is read, set(value) runs when it is assigned. In them, field is the value the property keeps. private set (or protected set, internal set) lets everyone read it and only that code assign it. 
class Account {
  var balance = 0
    private set
  var owner = ""
    set(value) { field = value.trim() }
  val isEmpty : bool get() => balance == 0
}
private, protected, internal, public
Who may use a declaration. private: a member only its class's code, a top-level declaration only its file. protected: that, and code written in a subclass, on objects of that subclass. internal: code of the same library (a program is one library; so is Jade). public is accepted and changes nothing: everything else is open to everyone.
lateinit
A var field given its value after the object is made. Reading it before that is an error.
lazy
A val whose value is worked out the first time it is read, and kept. 
class Config {
  lateinit var path : string
  lazy val size : int = path.size
}
atomic
A var field that any core of a parallel section may change, in one step, through +=, -=, = max(...), = min(...) and compareAndSet. 
class Tally { atomic var hits = 0 }
val tally = Tally()
(0 ..< 1000).toList().parallelStream().forEach { tally.hits += 1 }    // tally.hits is 1000
op
An operator of a class or value type: op +(other), op [](index), op ==(other) and the others, used as the operator is. 
value Money(val cents : int) {
  op +(other : Money) : Money => Money(cents + other.cents)
}
Money(150) + Money(250)    // Money(cents=400)
infix
A function of one parameter, a member or an extension, called between its two values with no dot or brackets. 
infix fun int.times(text : string) : string => text.repeat(this)
3 times "ab"    // "ababab"
inline
A function copied into each place it is called, with the lambdas given to it, so a lambda costs nothing and a return in it leaves the function around the call. 
inline fun twice(action : () -> unit) { action(); action() }
tail
Says that each call the function makes of itself is its last step. A function calling itself as its last step is made a loop with or without the word; with it, a call that is not its last step is an error. 
tail fun countDown(n : int) : int {
  if (n == 0) { return 0 }
  return countDown(n - 1)
}
suspend
A function that may wait (for a timer, a file, an answer), setting its task aside while it does. It is called only where waiting is possible: from another suspend function, at the top level of a script, or in the lambda given to task or thread. There is no await at the call. 
suspend fun later(x : int) : int {
  Thread.sleep(1.milliseconds)
  return x * 2
}
task { print(later(21)) }    // 42
throws
Written after a function's result type: the checked exceptions it may throw, which callers handle. The compiler works these out on its own inside a program; a library's public functions, and declarations with no body, say them. 
fun readConfig(path : string) : string throws IOException => Path(path).readText()
external
Only in the standard library: a function, property or object written in C++, declared in Astra so that its types and parameter names are known. It has no body. The reference below leaves the word out.

Choosing and repeating

if, else
Runs one block or the other. Written where a value is wanted, it gives the value of the block that runs; the braces are always written. 
val sign = if (count > 0) { "positive" } else { "not positive" }
when
Picks the first branch that fits: a value it equals, is Type, in a range or a collection, or, with no subject, a condition. Its value is that of the branch taken. when (val x = ...) names the subject for the branches. 
fun describe(x : any) : string {
  return when (x) {
    0 -> "zero"
    is string -> "a string"
    in 1..9 -> "a digit"
    else -> "something else"
  }
}
while, do
while (condition) { ... } repeats while the condition holds, testing it first; do { ... } while (condition) tests it after each run. 
do { n -= 1 } while (n > 3)
for, in
Goes over what a range, a list, a map, a set, a string or a sequence gives, an item at a time. a..b includes b, a..<b stops before it. 
for (i in 0 ..< 3) { write(i, " ") }    // 0 1 2
break, continue
break leaves the loop it is in; continue goes on to its next round. 
while (true) {
  n += 1
  if (n % 2 == 0) { continue }
  if (n > 5) { break }
}

Errors

throw
Stops the code with an exception, any Throwable: one of the standard library's (see errors.astra below) or a class of the program's own that extends Exception.
try, catch, finally
try runs a block; a catch (e : Kind) after it runs when the block throws an exception of that kind (catch (e) catches any Exception); finally runs last in every case, after any value to return is worked out. 
try {
  risky(-1)
} catch (e : IllegalArgumentException) {
  print("caught", e.message)
} finally {
  print("always")
}

Values, tests and types

true, false, null
The two values of a bool, and the absence of a value. Only a type written with ? (string?) holds null; x ?: other gives other when x is null, and x?.name gives null instead of failing. 
val maybe : string? = null
maybe ?: "none"    // "none"
and, or
Both, or either, of two conditions; the second is worked out only when the first does not already decide. ! is not. 
n > 0 and n < 10
is
Whether a value is of a type (!is: whether it is not). After a test that holds, the value is known to be of that type. 
if (anything is string) { print(anything.size) }
as
value as Type insists on the type, an error if it is not; as? gives null instead. In an import, as gives the module another name. 
val s = anything as string
val notInt = anything as? int    // null
in
Besides for: x in collection is whether the collection holds x (!in: whether it does not), and in a when, a branch for values in a range or a collection.
accepts
In a type argument of a list that may be changed: open List<accepts Button> takes a list of Button or of any type above it, to which a Button can be added. 
fun addButton(into : open List<accepts Button>) { into.add(Button()) }
val widgets : open List<Widget> = []
addButton(widgets)
open (in a type)
A list, map or set written plainly is one that may only be read; open List<T> is one that may be changed. In front of a declaration the word is an error (see below).
default
In an index, the value to give for a key a map does not have: counts[word, default = 0]. 
for (word in ["a", "b", "a"]) { counts[word] = counts[word, default = 0] + 1 }
it
The one parameter of a lambda that names none. 
[1, 2, 3].map { it * 10 }    // [10, 20, 30]

Files and libraries

import
Brings in another file or library: import NsText reaches its names as NsText.Block, import NsText.* by their bare names, import NsText as text under a name of the importer's choosing. A path of folders is written with dots, or in quotes (import "modules/strutil.astra"). The standard library needs no import: every program has all of it.
